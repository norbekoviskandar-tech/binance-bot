===========================================
BINANCE TRADING BOT - VERY SIMPLE GUIDE
===========================================

I've made this SUPER EASY for you.

Just 3 steps:

===========================================
STEP 1: Click SETUP.bat
===========================================

What it does:
- Installs everything automatically
- Sets up the bot
- Creates a file for your API keys

Just double-click: SETUP.bat

Wait for it to finish (takes 2-3 minutes).

===========================================
STEP 2: Add Your API Keys
===========================================

After SETUP finishes, it creates a file called .env

To add your keys:
1. Find the file named .env
2. Right-click it
3. Click "Open with" then "Notepad"
4. You'll see this:

   BINANCE_LIVE_API_KEY=your_live_key_here
   BINANCE_LIVE_API_SECRET=your_live_secret_here

5. Replace "your_live_key_here" with your actual API key
6. Replace "your_live_secret_here" with your actual API secret
7. Click File -> Save
8. Close Notepad

===========================================
STEP 3: Click RUN_BOT.bat
===========================================

Double-click: RUN_BOT.bat

The bot will start running and show you trading signals.

To stop it: Press Ctrl+C

===========================================
THAT'S IT!
===========================================

Your bot is now running on your computer.

===========================================
TO SEE THE DASHBOARD (optional):
===========================================

Double-click: DASHBOARD.bat

Then open your web browser and go to:
http://localhost:8501

This shows you the trading signals and bot status.

===========================================
IMPORTANT:
===========================================

- Keep your computer ON to keep the bot running
- If your computer sleeps, the bot stops
- If you want it to run 24/7, you need to disable sleep mode

To disable sleep in Windows:
1. Click Start
2. Type "Power & sleep"
3. Set "Sleep" to "Never"
4. Keep your computer plugged in
